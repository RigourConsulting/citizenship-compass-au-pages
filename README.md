# Citizenship Compass AU public pages

This repository hosts the official public documentation, compliance notices, privacy disclosures, and support guides for the Citizenship Compass AU Android application.

The site is published live via GitHub Pages at:
https://rigourconsulting.github.io/citizenship-compass-au-pages/

## Site structure

The public documentation site consists of static HTML pages formatted with accessible modern styling:

- `index.html`: Product overview, curriculum features, and pricing details
- `privacy/index.html`: Privacy policy and on-device data storage disclosures
- `support/index.html`: Frequently asked questions, test formats, and user help
- `terms/index.html`: Terms of service, educational disclaimer, and refund terms
- `accessibility/index.html`: WCAG 2.1 Level AA conformance and assistive technology features
- `sources/index.html`: Official Commonwealth publications, licensing, and attribution
- `contact/index.html`: Publisher contact and inquiry channels
- `404.html`: Accessible error handling and navigation fallback
- `robots.txt`: Search crawler indexing instructions
- `sitemap.xml`: Complete search sitemap
- `.nojekyll`: Bypasses Jekyll processing on GitHub Pages

## Architectural boundary

This public repository contains only public documentation and static web assets.

The complete Android application source code, proprietary algorithms, psychometric calibration engines, and item banking tools are securely maintained in a separate private repository. No private application code or API credentials are included in this repository.

## Maintenance and writing standard

All text in this repository adheres to the Citizenship Compass AU writing standard:

- Natural Australian English spelling and phrasing
- Sentence case headings
- No colons in headings, titles, or subtitles
- No Unicode en dashes (U+2013) or em dashes (U+2014)
- Clear, respectful, and accessible language for human readers
