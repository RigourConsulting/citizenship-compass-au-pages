Accessibility statement

Last updated: 4 October 2026

Commitment to accessible civics learning

Citizenship Compass AU is built using accessibility-informed design principles. We aim to conform with the Web Content Accessibility Guidelines (WCAG) 2.2 Level AA across our Android application and public web pages.

Our accessibility approach

Civics education should be barrier-free for all learners, including older adults, individuals with visual impairments, neurodivergent individuals, and candidates using assistive technologies. Rather than relying on automated scores alone, our application undergoes physical hardware testing on real Android devices to verify accessible interactions in practice.

Implemented and verified Android accessibility features

The current Android implementation includes the following verified accessibility features:

Screen readers

TalkBack screen reader support

Every interactive element features descriptive content descriptions. Question sessions announce current progress (such as "Question 4 of 20"), practice cards report selection states, and headings use semantic hierarchy so you can navigate by heading using screen reader gestures.

Typography

Dynamic font scaling up to 200 percent

The user interface adapts gracefully to system font scale settings up to 2.0x (200 percent). Containers and cards expand vertically, text flows naturally, and touch controls remain completely accessible without clipping or awkward line truncation.

Touch targets

Generous touch targets

Buttons, option cards, navigation icons, and settings toggles maintain interactive touch targets meeting or exceeding 48 by 48 density-independent pixels (dp), with generous spacing to avoid accidental taps.

Contrast

Contrast and colour independence

Body text, headings, and interactive elements satisfy WCAG 2.2 AA contrast ratios (at least 4.5:1 for normal text and 3:1 for large text). Important information is never conveyed by colour alone: answer feedback pairs distinct iconography (check marks and cross marks) and text descriptions with colours.

Theming

Light, Dark and Dynamic Colour modes

Choose between Force Light, Force Dark, and System Default appearance. The Dark theme utilizes a true black AMOLED background (#0B0F19) to reduce glare and visual fatigue. Dynamic Colour harmonises interface accents with device themes on supported Android versions.

Reduced motion

Reduced motion support

When reduced motion is enabled in system accessibility settings, animated transitions and decorative movements are disabled or replaced with immediate state changes to prevent motion discomfort.

Audio speech

Text to speech assistance

During practice sessions, you can listen to question prompts and answer options read aloud through Android's native text-to-speech synthesis, with full pause, resume, and stop controls.

Physical verification

Physical device testing

All accessibility behaviours have been tested and verified on physical Samsung Galaxy A56 hardware running Android 16 (API 36) with Samsung TalkBack and One UI 8.5 gesture navigation.

Future platform accessibility

iOS accessibility foundation

An iOS version of Citizenship Compass AU is planned. It will be developed to support Apple VoiceOver, Dynamic Type font scaling, Dark Mode, and AssistiveTouch. Platform-specific accessibility documentation will be published before the iOS release.

Conformance target and ongoing testing

Our stated accessibility target is WCAG 2.2 Level AA. While we conduct ongoing internal and physical device testing, we do not claim formal third-party certification. We actively welcome feedback from learners using assistive technologies to help us identify and resolve barriers.
